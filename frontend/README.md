# 爱学纪 · 学生端前端演示

沿用原有学生端框架与 V1.1 复习闭环。使用 React、TypeScript 和 Vite；React Router 管理页面，TanStack Query 管理请求状态，Zustand 管理 Mia 上下文，React-PDF 渲染本地示例讲义。同源 `/api/*` 请求由 Mock Service Worker 模拟，开发服务器和生产预览都使用同一组模拟接口。

## 本地运行

在 `D:\AI_learning\frontend` 中执行（已用 Node.js 24 与 pnpm 11 验证）：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

打开 `http://127.0.0.1:5173`。不要通过 `file://` 打开页面，浏览器需要允许本地 Service Worker。

如果端口已被占用，可用 `pnpm dev --port 5174 --strictPort`，打开 `http://127.0.0.1:5174`。浏览器按访问地址和端口隔离演示记录；换端口不会删除旧数据，但也不会显示旧端口的数据。

```powershell
pnpm build
pnpm preview --port 5173
```

第二组命令运行生产构建的本地预览。已运行开发服务器时，请先结束它或指定另一个空闲端口。

## 演示路径

1. 数学：课程 → 初中数学 → 一元一次方程单元 → 讲义 → 选择例题 02 → 打开 Mia → 开始分步辅导 → 核对辅导答案 → 查看并确认保存复盘。空间可重新打开复盘，并从来源返回原题。
2. 科学与 PET：进入两门课程的当前单元，分别做植物光照观察和图书馆短对话阅读，核对答案、读解析、返回课程；也可以对当前题唤起 Mia 的示例提示。
3. 工具：拍题、讲解、摘要、思维导图、播客脚本、闪卡、测验可编辑并确认保存。在 Space 点击对应成果，再选「在工具中重新打开」，有来源的成果可定位回原页或原活动。重新打开后再次保存会保留原件。闪卡自评和测验作答为本次练习，保存的是卡片和题库，不是练习成绩。
4. 分镜：在例题 02 的 Mia 面板预览、修改分镜脚本，确认后体验排队、生成、模拟失败和重试，再逐幕查看并保存。分镜保留到原题的链接，不生成视频或音频。

复盘保存后，复习建议默认安排到次日，可修改标题和日期。只有确认才写入今日；拒绝不生成任务。从今日进入复习会回到原来的讲义页和选区，可立即试做独立变式，不用等待计划日期。成长页分开记录「有提示练习」和「独立练习」，保存复盘本身不算练习通过。

Mia 在桌面讲义页与阅读区并排，在较窄视口使用覆盖面板。翻页不会改变已带入的题目；可在面板里主动切换并恢复本次浏览中的会话。Today 会记录最近学习位置，复习任务可查看、改期或回原题；Growth 可按课程、日期、依据和练习方式筛选并查看记录详情。建议、任务、已确认成果、分镜任务及练习证据保留在当前浏览器的同一访问地址；Mia 对话与未保存的复盘不跨刷新。

工具和辅导使用注册示例或可编辑模板。拍题图片只在当前页面本地预览，示例识别使用固定文字；播客只产出脚本。未新增完整 Live Tutor，未接入真实 AI、后端、OCR、语音、视频、云同步或通知，也不会开启麦克风或摄像头。演示记录不代表正式成绩或掌握结论。

## 验证

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm build
$env:PW_PRODUCTION = '1'
pnpm test:e2e
```

Playwright 默认使用本机安装的 Google Chrome，亦可将 `PW_CHROME_CHANNEL` 设为本机已有的 `msedge`。生产测试在独立的 4173 端口启动预览，验证 390px、768px、1440px 三种视口。端到端截图保存在 `test-results`。
